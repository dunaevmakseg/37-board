# 37 Board — «Chalk & Ink»

> Расширенный, переструктурированный справочник по проекту.
> Цель файла — чтобы по нему можно было понять **структуру проекта** и **роль каждой сущности**: что хранится, что рисуется, что делает каждый флаг и экран.

**Live:** https://dunaevmakseg.github.io/37-board/
**Репо:** https://github.com/dunaevmakseg/37-board

---

## 1. Что это

Мобильное веб-приложение (PWA-like) для скалолазов — трекер трасс боулдеринг-зала на интерактивной светодиодной панели (по образу Kilter Board).
Single-page app на чистом vanilla JS. Внутри «рамки телефона» по центру экрана живёт само приложение, а рядом (на широких экранах) — **Студия темы** для живой настройки оформления.

Ключевые возможности:
- Лента трасс с поиском, сортировкой и фильтрами.
- Просмотр трассы: доска с подсвеченными зацепами, свайп между трассами.
- Создание/редактирование трассы прямо по доске (выбор типа зацепки → тап по holds).
- Профиль: статистика по категориям, логбук (сессии пролазов), коллекции трасс.
- Уведомления, списки подписчиков/подписок, чужие профили.
- Студия темы: цвета, шрифты (с Google Fonts), фактура, пресеты, экспорт CSS.

## 2. Стек

| Слой | Технология |
|------|------------|
| Логика | Vanilla JS (ES6, IIFE-модули, без сборки) — работает даже с `file://` |
| Разметка/стили | HTML + CSS-переменные + Tailwind Play CDN (utility-классы ссылаются на те же CSS-переменные) |
| Хранилище | `localStorage` (профиль и тема) |
| Иконки | Кастомный inline-SVG-набор (`icons.js`, `window.ICONS`) |
| Шрифты | Google Fonts (Fraunces + Spectral по умолчанию; остальные грузятся по требованию) |
| Деплой | GitHub REST API → GitHub Pages (git на машине не установлен) |

Цветовая идея: монохром (ink/chalk), пастель — только там, где она несёт смысл (роли зацепов).

### Порядок подключения скриптов (важен!)
`index.html` грузит их строго в этом порядке, потому что каждый последующий читает `window.*` из предыдущего:

```
icons.js  →  data.js  →  app.js  →  panel.js
```

- `icons.js` кладёт `window.ICONS`.
- `data.js` кладёт `window.BOARD`, `CLIMBS`, `ANGLES`, `ROLE_META`, `GRADE_SCALE`, `LOGBOOK`, `GRADE_COUNTS`, `FOLDERS`, `NOTIFICATIONS`.
- `app.js` всё это читает и строит приложение.
- `panel.js` независим — управляет только CSS-переменными и темой.

## 4. Глоссарий данных (`data.js`)

Это «модель» приложения. Сейчас всё синтетическое и **детерминированное** (seeded PRNG `mulberry32`), поэтому доска и трассы выглядят одинаково при каждой перезагрузке. Позже файл целиком заменяется реальной раскладкой панели + API.

### 4.1. Доска — `BOARD`
Геометрия физической панели подсветки. Треугольная (гексагональная) сетка зацепов: 11 в ряду × 21 ряд, шаг 20 см, чётные/нечётные ряды смещены на полшага.
```js
BOARD = { cols, rows, W, H, holds: [ { id, col, row, cx, cy, r, rot, path } ] }
```
- `cx, cy` — координаты зацепа в SVG. `path` — органическая «галечная» форма (blob, Catmull-Rom). `rot` — случайный поворот.
- `holds` рисуются один раз и кешируются (`BASE_HOLDS` в `app.js`); для каждой трассы поверх рисуются только цветные кольца.

### 4.2. Трасса — `CLIMBS[i]`
Главная сущность приложения. Массив из 18 трасс. Поля одной трассы:

| Поле | Что значит |
|------|------------|
| `id` | внутренний идентификатор (индекс) |
| `idx` | номер-бейдж трассы (начинается с 79 — как на референс-скриншоте) |
| `name` | название трассы («Lament of the Steep») |
| `setter` | автор-сеттер (кто поставил трассу) |
| `fa` | First Ascent — кто сделал первое прохождение (может быть `null`) |
| `ascents` | сколько раз трассу прошли (для сортировки «Популярные») |
| `font` | категория сложности по French-шкале («6b+») — показывается в UI |
| `v` | та же сложность по V-шкале («V4») |
| `vNum` | числовая сложность (для фильтра/сортировки по грейду) |
| `stars` | оценка качества трассы, 0–3 звезды |
| `holds` | список зацепов трассы: `[{ h: holdId, role }]` |
| **`saved`** | трасса добавлена пользователем в коллекцию (закладка). Кнопка «папка» в просмотре, фильтр «Только лайки» |
| **`logged`** | пролаз отмечен как засчитанный (галочка в actionbar) |
| **`swag`** | особый флаг «стильной» / эталонной трассы. Рисует тег `#SWAG` в шапке трассы; есть фильтр «Только SWAG» |
| **`noMatch`** | правило «no matching» — нельзя держаться двумя руками за один зацеп. Рисует перечёркнутую иконку рук в шапке |
| **`noKick`** | трасса без kickboard (нижней наклонной панели). Влияет на тег: `no kickboard` (красный) либо `kickboard` (зелёный) |

> Трасса `CLIMBS[0]` («Lament of the Steep») намеренно помечена `noMatch + swag + noKick`, чтобы продемонстрировать все спец-флаги сразу.

### 4.3. Роли зацепов — `role` / `ROLE_META`
Каждый зацеп трассы имеет роль, она задаёт цвет кольца и подпись:

| `role` | Подпись | CSS-цвет | Смысл |
|--------|---------|----------|-------|
| `start` | Старт | `--start` (зелёный) | стартовые зацепы (низ доски) |
| `hand` | Зацепы | `--hand` (голубой) | зацепы для рук (тело трассы) |
| `foot` | Ноги | `--foot` (персиковый) | зацепы только для ног |
| `finish` | Топ | `--finish` (фиолетовый) | финишные зацепы (верх доски) |

`ROLE_META` (в `data.js`) — связка `role → {label, color}` для легенды. `ICONS.ROLE` (в `icons.js`) — иконки ролей для палитры-кисточек в редакторе.

### 4.4. Шкала сложности — `GRADE_SCALE`
Массив French-грейдов `['6a', '6a+', … '8a']`. Индекс в массиве (`gi`) используется как «номер категории» в логбуке и диаграмме.

### 4.5. Логбук — `LOGBOOK` + `GRADE_COUNTS`
Лента личных пролазов пользователя (мок: 11 сессий). Одна запись:
```js
{ id, name, font, gi, dateKey, ts, attempts, flash, setter, stars }
```
- `gi` — индекс категории в `GRADE_SCALE`.
- `dateKey` / `ts` — группировка по дням (сессиям) и сортировка по времени.
- `attempts` — число попыток; `flash` = `true`, если пролаз с первой попытки.
- `GRADE_COUNTS[i]` — сколько записей логбука приходится на категорию `i`. Это данные для гистограммы «Категории» в профиле.

### 4.6. Коллекции — `FOLDERS`
Тематические подборки трасс (бывшие «папки»):
```js
{ name, public: bool, climbs: [{ name, font, gi }] }
```
- `public` — публичная (глобус) или приватная (замок).
- В UI: вкладка «Коллекции» в профиле, открытие → список трасс коллекции.

### 4.7. Уведомления — `NOTIFICATIONS`
Лента событий. У каждой записи `kind` определяет иконку и цвет:

| `kind` | Иконка | Пример |
|--------|--------|--------|
| `like` | сердце | «оценил твой пролаз» |
| `comment` | реплика | «прокомментировал…» |
| `follow` | user+ | «подписался на тебя» |
| `route` | гора | «поставил новую трассу» |
| `system` | инфо | «доступна новая прошивка» |

### 4.8. Прочее
- `ANGLES` — список доступных углов наклона панели (10°…70°). Выбирается «пилюлей» в шапке ленты.

## 5. Архитектура `app.js`

Один IIFE. Делится на блоки (помечены комментариями-разделителями).

### 5.1. Глобальное состояние — `state`
```js
state = { tab, angle, query, sort, filters:{vMin,vMax,minStars,likedOnly,swagOnly}, climbIndex }
```
Управляет лентой трасс: активный таб, угол, поисковый запрос, сортировка, фильтры, индекс открытой трассы.
`currentList()` — применяет к `CLIMBS` поиск + фильтры + сортировку и возвращает готовый список.

### 5.2. Хелперы
`$` (querySelector), `h(html)` (DOM из строки), `screenEl(html)` (секция-экран), `fmt` (числа в ru-RU), `icon(name)`, `plural(n, forms)` (русские склонения), даты (`dShort`, `dLong`, `tTime`).

### 5.3. Рендер доски
- `DEFS` — SVG-градиент для объёма зацепа.
- `BASE_HOLDS` — все зацепы доски, посчитаны один раз.
- `ringsFor(climb)` — цветные кольца поверх зацепов трассы.
- `renderBoardSVG(climb)` — собирает итоговый `<svg class="board">`.

### 5.4. Роутер (стек экранов)
- `setRoot(buildFn)` — меняет корневой экран таба (с кроссфейдом).
- `pushScreen(buildFn)` — кладёт оверлей-экран поверх (анимация «вперёд»).
- `popScreen()` — снимает верхний оверлей (анимация «назад»).
- Порядок наложения задаётся **порядком в DOM**, без `z-index` (см. комментарий в `styles.css`).

### 5.5. Тосты и шиты
- `toast(msg)` — всплывающее уведомление снизу.
- `openSheet(html, onMount)` / `closeSheet()` — нижний bottom-sheet (свайп вниз закрывает). На шитах построены: выбор угла, сортировка, фильтры, смена доски, диапазон категорий, меню трассы.

### 5.6. Экраны (builder-функции)

| Функция | Экран | Назначение |
|---------|-------|------------|
| `buildHome()` | **Лента трасс** (таб «Трассы») | шапка (доска/угол/добавить), поиск, счётчик, сортировка, список `rowHTML` |
| `buildDetail(list)` | **Просмотр трассы** | шапка (`headHTML`: имя, set/FA, теги swag/kick, грейд, звёзды), свайпуемая доска (`mountDeck`), `actionbar` |
| `buildCreate(existing)` | **Создание/Редактирование** | палитра кисточек (`BRUSHES`), тап по holds расставляет зацепы, публикация требует старт+финиш |
| `buildProfile(opts)` | **Профиль** (свой или `opts.visited` чужой) | шапка-обложка, аватар/статистика, диаграмма категорий, сегмент «Все трассы / Коллекции», логбук |
| `buildUserList(type, n)` | **Подписчики / Подписки** | мок-список пользователей |
| `buildNotifications()` | **Уведомления** | лента `NOTIFICATIONS` |
| `buildFolder(folder)` | **Коллекция** | трассы выбранной коллекции |
| `buildPlaceholder(...)` | **Заглушка** | пустые/будущие разделы (таб «Ещё») |

### 5.7. Просмотр трассы — детали
- `headHTML(c)` — шапка: строит теги в зависимости от флагов (`swag`, `noMatch`, `noKick`), грейд, звёзды; имена `setter`/`fa` кликабельны → чужой профиль.
- `actionsHTML(c)` — пять кнопок: подсветка, бета, **отметить пролаз** (`logged`), пролазы, **в коллекцию** (`saved`). Часть пока показывает тост «скоро».
- `mountDeck(deck, list, onChange)` — pointer-свайп с «резиной» на краях; смена карточки синхронно обновляет шапку.

### 5.8. Профиль — детали
- `profileState = { view:'all'|'folders'|'folder', sort, gMin, gMax, folderIdx }` — состояние списка профиля.
- `profileData` — сохраняемые данные профиля (см. `DEFAULT_PROFILE`): имя, username, статус, аватар, фон, подписчики/подписки/ачивки, соцсети. Хранится в `localStorage` под `board37.profile`.
- `saveProfile()` — запись в localStorage.
- `chartBars()` — гистограмма категорий по `GRADE_COUNTS`. Ось Y: `N` округляется (≥50 → кратно 10, иначе кратно 5), `step = N/5`, 6 меток.
- `renderProfileList(scope)` — рендерит логбук (с группировкой по сессиям при сортировке по дате) / список коллекций / трассы коллекции; синхронизирует сегмент-контрол.
- Режим редактирования (`.is-edit` на экране): кнопка-кисточка → галочка, поля становятся `contenteditable`, аватар и фон выбираются через файл → `FileReader` → data URL → localStorage. Поле username защищает символ `@`.
- `SOCIAL_NETS` — конфиг соцсетей; `renderSocials()` рисует ссылки-иконки. Чтобы добавить сеть: иконка в `social-icons/` → запись в `SOCIAL_NETS` → запись в `profileData.socials`.
- `visitedProfile(username)` — детерминированный мок чужого профиля (по хешу имени).

### 5.9. Таб-бар — `TABS` / `renderTabs` / `switchTab`
```js
TABS = [
  ['boards',  'boards',   'Трассы',  () => buildHome()],
  ['profile', 'user',     'Профиль', () => buildProfile()],
  ['more',    'ellipsis', 'Ещё',     () => buildPlaceholder(...)],
];
```
`switchTab(key)` меняет `state.tab` и зовёт `setRoot` соответствующего билдера.

### 5.10. Инициализация
`renderTabs()` → `setRoot(buildHome)`. Поддержан deep-link: `index.html#c=3` сразу открывает трассу с `id=3`.

## 6. Иконки — `icons.js`

`window.ICONS` — словарь inline-SVG. Большинство строятся хелпером `svg(paths)` (тонкая обводка, `currentColor`, round caps).
- Иконки интерфейса: `back, next, plus, close, search, sliders, bulb, check, bookmark, more, info, camera, tripod, folder, beta, bell, user, sort, flag, chevronDown, lock, globe, brush, mountain, ellipsis`.
- Таб-бар: `boards, user, ellipsis`.
- Уведомления: `heart, comment, userPlus` (+ `mountain`, `info`).
- Спец-флаг: `noMatch` (перечёркнутые руки).
- Роли зацепов: `roleStart, roleHand, roleFoot, roleFinish`, собраны в `ICONS.ROLE`.
- Звёзды: `ICONS.star(on)` — заполненная/пустая.

`icon(name)` в `app.js` умеет вызывать как функции (`star`, динамические), так и строки.

## 7. Студия темы — `panel.js`

Независимый модуль. Меняет CSS-переменные на `:root` → перекрашивается всё (и кастомный CSS, и Tailwind-утилиты, т.к. они ссылаются на те же переменные).

- **Модель темы:** `colors` (11 токенов: ink/chalk/линии + цвета ролей + звёзды), `fontDisplay`, `fontBody`, `grain` (зерно-шум), `lineAlpha` (толщина линий).
- `computeVars(t)` → набор CSS-переменных; `apply(t)` — записывает их в `:root`; `persist(t)` — сохраняет в `localStorage` под `board37.theme` (вместе с готовыми `vars` и списком нестандартных шрифтов — чтобы `index.html` восстановил тему **до первой отрисовки**, без мигания).
- **Шрифты:** `fontField` — поиск + ленивая подгрузка превью (`IntersectionObserver`). Каталог берётся из Fontsource API (только шрифты с кириллицей), с надёжным встроенным фолбэком `FALLBACK_FONTS`.
- **Пресеты:** `Chalk & Ink` (дефолт), `Бумага`, `Неон-ночь`, `Сепия`.
- **Экспорт:** кнопка «Скопировать CSS» отдаёт `:root { … }`.
- **Видимость:** на широких экранах панель сбоку (можно скрыть), на узких (`≤880px`) — выезжающий справа drawer (`panel-open`). Кнопка-шестерёнка `#panel-toggle`.

Панель **намеренно не темизируется** переменными приложения (свой набор `--p-*`), чтобы оставаться читаемой, пока крутишь цвета приложения.

## 8. Стили — `styles.css`

Один файл, разбит по секциям:
- **`:root`** — палитра (ink/chalk/линии + роли + `--red`), easing-кривые, размеры (`--app-w`, `--tab-h`), типографика/фактура (управляются панелью).
- **Каркас:** `.workbench` (устройство + панель по центру), `.page-aura` (фоновое свечение), `.app` (рамка телефона со скруглением на ≥480px), `.grain` (шум-зерно).
- **Стек экранов:** `.stage`, `.screen` + keyframe-анимации переходов (`enterRight/exitLeft/…`) и `.reveal` (ступенчатое появление списков).
- **Чром:** `.topbar`, `.label`, `.iconbtn`, `.search`.
- **Лента:** `.row`, `.row__name/meta/count/grade`, `.stars`.
- **Таб-бар:** `.tabbar`, `.tab`.
- **Bottom-sheet:** `.sheet*`, `.chip`, `.angle-*`.
- **Просмотр трассы:** `.detail-*` (включая `--swag/--kick/--nokick` теги), `.board*`, `.ring--{role}`, `.actionbar`, `.btn*`, `.brush*` (палитра редактора).
- **Профиль:** `.prof-*` (обложка, аватар, статистика, режим `.is-edit`), `.chart*` (гистограмма), `.seg*` (сегмент-контрол), `.sess/.log-*` (логбук), `.folder*` (коллекции), `.note*` (уведомления), `.f-slider*` (двуручковый слайдер грейда), `.ulist-*` (списки людей).
- **Панель темы:** все `.pnl-*` со своими `--p-*` переменными.
- Уважается `prefers-reduced-motion`.

## 9. Хранилище (`localStorage`)

| Ключ | Что хранит | Кто пишет/читает |
|------|------------|------------------|
| `board37.profile` | данные профиля (имя, username, статус, аватар, фон, соцсети…) | `app.js` (`saveProfile`) |
| `board37.theme` | тема: цвета, шрифты, фактура + готовые CSS-vars + нестандартные шрифты | `panel.js` (`persist`), читается в `index.html` до первой отрисовки |

> Сами трассы, логбук, коллекции, уведомления — пока **в памяти** (мок из `data.js`), не персистятся. Изменения `saved`/`logged`/`swag` живут до перезагрузки.

## 10. Деплой на GitHub

Git на машине **не установлен** → деплой через GitHub REST API (Contents). При пуше в `main` отрабатывает `.github/workflows/deploy.yml` и публикует на GitHub Pages.

```powershell
$token = "<PAT>"
$repo  = "dunaevmakseg/37-board"
$hdrs  = @{ Authorization = "token $token"; Accept = "application/vnd.github.v3+json"; "User-Agent" = "PS" }

function Push-File($localPath, $repoPath) {
```
